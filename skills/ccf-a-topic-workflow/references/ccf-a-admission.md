# CCF-A 主选题准入规则

用于筛出值得以 CCF-A 为目标投入的研究问题。判定针对当前可核实的选题证据和拟贡献。研究结果、论文质量与录用在后续阶段另行判断。

| 条件 | 达到推荐标准所需的证据 |
| --- | --- |
| **1. 问题与影响有证据** | 说明问题在什么条件下发生，影响什么能力、认识或实际需求。引用可定位的论文证据，并区分已观察现象和对成因的推断。具有实质后果的可靠反例也可作为证据。两组结果同时改变关键因素时，仅用它们支持所观察的差异，对单一因素的归因保留为待核实。 |
| **2. 拟贡献经得起近邻比较** | 核对最接近的研究问题和机制，两者可来自不同论文。逐条说明已有工作做到哪里，候选将增加什么、为什么这个差异重要、怎样辨别贡献是否成立。核心主张已被覆盖时删掉或重定位。只换模型、调权重、更换数据集或报告小幅涨点，需要进一步说明由此获得的新能力或新认识。 |
| **3. 有同方向的真实发表对标** | 核对至少一篇来自同方向、且与问题或贡献类型匹配的 CCF-A 正式论文。用 [CCF 官方目录](https://www.ccf.org.cn/Academic_Evaluation/By_category/) 核实领域及级别，用正式论文集或期刊核实文章类型和版本。依据引言、方法或分析段比较问题重要性、贡献类型与所需证据，说明候选有何可比的研究价值。对标与查新分别记录，同一文章可承担两个角色。 |
| **4. 最强审稿质疑有实质回应** | 针对候选提出一个最可能阻止进一步投入的质疑，例如已被近邻覆盖、关键现象归因不成立、主要机制与现成做法实质等价。用原文、清楚的论证或更精确的问题定义回应。关键事实待核实时留在预研。拟贡献本身可以待实现，现有证据应足以支持继续投入，并说明哪些结果会推翻它。 |

## 判定和收敛

- 对每个有希望的候选记录四项判定，使用「通过」「未通过」「待核实」，每项附依据。分开核查问题本身与各条拟创新点，同步移除缺乏依据的附加贡献。
- 沿会导致相反结论的线索复核，例如搜索同义问题、最接近工作是否同式，以及后续论文是否已给出反例或解法。条件允许时由另一位评审者复核，否则单独以审稿视角复核并标明方式。可选 skill 给出的分数或结论需要原文依据。
- 用户指定 venue 时按其方向及文章类型评议。未指定时，选最匹配的 CCF-A 领域和代表性正式论文并说明选择理由。仅确认会议等级、仅见题目或摘要，或缺少同方向的有效对标时，标为待核实。受限语料同样按实际可核实范围判断。
- 有可辩护的剩余问题时，可沿证据改题或扩大到相邻研究方向，再核查发生变化的问题与创新点。没有可靠的重写路径或无法取得关键证据时，记录需要补查的最小信息。
- **四项均通过才能列为主选题。** 有潜力但关键证据待核实的项列为「预研」，被覆盖或贡献缺乏实质差异的项列为「淘汰」。没有通过项时明确报告零项推荐。说明取舍依据，无需预测录用率、强制要求数学证明或编写实验计划。
