# 从文献到研究选题

将用户提供的论文作为起点，交付研究方向图、文献对照表、查新记录和通过筛选的 CCF-A 主选题。每个主选题写明要解决的问题、为什么选它、拟创新点及其与最接近工作的区别。评审范围是选题及拟贡献。

使用 PDF、DOI、论文链接、本地目录或用户提供的摘要和摘录作为输入。根据种子论文推断研究范围及适合对标的领域，优先使用用户指定的目标 venue、track 和时间范围。尚无种子论文时，提供可接收的输入形式，待有论文后再做文献分析。

## 执行顺序

1. **建立方向图。** 确认种子论文的身份和版本，按研究问题与技术路线归类。追踪关键引用、后续工作和反例，注明覆盖边界。用户限制来源时遵守指定范围，并在结论中体现覆盖限制。
2. **提取已有成果和局限。** 阅读论证所需的正文、方法、结果及附录。记录已解决的问题、方法、假设、成立条件及仍有待回答的问题。每条关键判断给出可取得的论文链接或材料编号，以及页码、章节、图或表，并区分作者自述、结果所示、分析推断和未报告。
3. **形成候选研究问题。** 优先考虑有明确后果的失效条件、共同假设、矛盾结果或尚未解决的限制。把候选写成「在什么条件下，要解决什么问题，解决后会带来什么能力或认识」。给每条拟创新点写出可比较的主张，连回提出它的文献证据。
4. **查新。** 用问题、约束和拟改变的机制分别检索，追踪代表作的后续引用，纳入相关预印本。阅读决定结论的近邻全文部分，分别记录问题和每条拟创新点的覆盖情况。保留检索范围、关键词、日期与未能取得的证据。
5. **审核 CCF-A 主选题。** 按 [CCF-A 准入规则](references/ccf-a-admission.md) 核对四项：问题证据、创新增量、发表案例对标、最强反对意见。区分已通过查新的候选与通过全部准入条件的主选题。如果原候选未达标且证据支持另一种问题界定，补查并重审新表述。
6. **按结果交付。** 只把通过四项的题放进「CCF-A 主选题推荐」，按证据与贡献排序。没有通过项时写「本轮无 CCF-A 主选题」，并给出预研或淘汰原因。通常推荐 1–3 项，以实际通过数量为准。

按 [证据与查新规则](references/evidence-and-review.md) 判断候选，按 [输出模板](references/output-templates.md) 交付。可选 skills 的分工见 [模块分工](references/skill-routing.md)。
