# 从文献到研究选题

将用户提供的论文作为起点，交付研究方向图、文献对照表、查新记录和少量有证据的候选选题。每个选题写明要解决的问题、为什么选它、拟创新点及其与最接近工作的区别。默认完成选题与贡献核查；实验计划属于单独任务。

使用 PDF、DOI、论文链接、本地目录或用户提供的摘要和摘录作为输入。根据种子论文推断研究范围，目标会议、track、时间范围和候选数量可由用户指定。尚无种子论文时，提供可接收的输入形式，待有论文后再做文献分析。

## 执行顺序

1. **建立方向图。** 确认种子论文的身份和版本，按研究问题与技术路线归类。追踪关键引用、后续工作和反例，注明覆盖边界。用户限制来源时遵守指定范围，并在结论中体现覆盖限制。
2. **提取已有成果和局限。** 阅读论证所需的正文、方法、结果及附录。记录已解决的问题、方法、假设、成立条件及仍有待回答的问题。每条关键判断给出可取得的论文链接或材料编号，以及页码、章节、图或表，并区分作者自述、结果所示、分析推断和未报告。
3. **形成候选研究问题。** 优先考虑有明确后果的失效条件、共同假设、矛盾结果或尚未解决的限制。把候选写成「在什么条件下，要解决什么问题，解决后会带来什么能力或认识」。给每条拟创新点写出可比较的主张，连回提出它的文献证据。
4. **查新。** 用问题、约束和拟改变的机制分别检索，追踪代表作的后续引用，纳入相关预印本。阅读决定结论的近邻全文部分，分别记录问题和每条拟创新点的覆盖情况。保留检索范围、关键词、日期与未能取得的证据。
5. **审查贡献，交付选题。** 对每条拟创新点比较最接近工作，说明实质差异及其价值。筛掉已被覆盖或缺乏可辩护差异的主张，将待核实候选单列。优先给出 1–3 个有足够证据的选题；根据证据可给更少或不给。说明筛选及排序依据。

按 [证据与查新规则](references/evidence-and-review.md) 判断候选，按 [输出模板](references/output-templates.md) 交付。额外 skills 可用于对应环节，选用规则见 [模块分工](references/skill-routing.md)。
